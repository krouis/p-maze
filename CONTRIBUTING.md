# Contributing to Pixel Maze

Thank you for your interest in contributing! This project is an experiment in AI-assisted game development, and we welcome contributions from both humans and AI coders.

## Development Setup

### Prerequisites

- **Node.js**: Version `20.x` (LTS) is required. You can use [nvm](https://github.com/nvm-sh/nvm) to manage it:
  ```bash
  nvm use
  ```

### Installation

1. Fork and clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```

### Daily Development

- Run the dev server locally:
  ```bash
  npm run dev
  ```
- Format your code:
  ```bash
  npm run format
  ```
- Lint and type-check:
  ```bash
  npm run lint
  npm run typecheck
  ```

## Quality and Verification

Before submitting any code changes, ensure all verification checks pass by running:

```bash
npm run check
```

This runs Prettier checking, ESLint linting, TypeScript compiler checks, and all Vitest unit tests.

### Running End-to-End Tests

Playwright tests verify desktop, mobile layout, and offline caching behaviors:

```bash
npx playwright install chromium
npm run test:e2e
```

## Guidelines

1. **Child-Friendly Design**: Keep the game simple, peaceful, and forgiving. Never add timers, stress, health bars, game-over failure states, red flashing warnings, advertisements, or tracking scripts.
2. **AI Disclosure**: If your contributions are significantly generated by an AI coding assistant, please clearly disclose it in your pull request description (e.g. including tool names, prompts, or workflows used) for our records.
3. **No External Assets**: All sound effects and melodies must be procedurally generated via Web Audio API. Do not include copyrighted images or MP3 audio.
4. **Code Quality**: Preserve TypeScript strict compilation settings and write comprehensive unit tests for any new helper functions or state machine updates.
