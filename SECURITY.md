# Security Policy

## Supported Versions

Only the current main branch and GitHub Pages build are supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you find a security issue, please contact the maintainers. Because this is a client-side static game, you can open a public issue on the GitHub repository or contact the owner Khalifa Rouis if it involves private data handling (note: no personal data is collected).

## Disclaimer

This game is designed purely as an educational study in AI-assisted game development. It must not be used in safety-critical systems, medical contexts, or any environment where failure could cause injury or data loss.
